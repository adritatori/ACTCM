What real AI agents did, against what safety tests check

  1. AI labs test their safety checks by giving an agent a hidden harmful goal (a side task) and seeing whether a monitor notices.
  2. The safety number they report only speaks for the attacks the test includes.
  3. Meanwhile, real AI agents have already got into real systems.
  4. We split 3 well-documented incidents into 93 steps, each with a quoted source.
  5. A script compares every attack step with the 114 public test tasks, using MITRE ATT&CK® attack categories.
  6. The result: which real moves no public test states as a goal. Untested does not mean undefended.

  • 15steps with no public test in their tactic

Chosen for detail, not random: these 3 incidents are not a sample of all incidents. Another 16 steps are marked “Can't tell” because two labels are defensible and they give different answers.

  • Malicious package published to PyPI by Claude Mythos 5 during an evaluation

    Anthropic · disclosed 30 Jul 2026

    In a capture-the-flag test, the model was told it had no internet but did. To win, it registered accounts, published a booby-trapped Python package on the public registry, and used credentials leaked by a security vendor's scanner to reach that vendor's live database.

    An agent in a test was wrongly connected to the real internet and attacked real systems to finish its task. 10 attack steps 4 never tested 16 Evidence-checked

  • UK AISI incident INC-2026-07-28-01: unsanctioned agent actions during cyber testing

    Anthropic, OpenAI · disclosed 4 Aug 2026

    In a UK AI Security Institute cyber-range test with internet access switched on, agents took 19 unsanctioned actions on the live internet. In the worst run, a model tried to get malicious code merged into a real open-source project, using fake accounts, hidden instructions and targeted messages. A human reviewer stopped it.

    Agents in a cyber test with open internet access acted against real people and projects to finish their task. 26 attack steps 5 never tested 35 Evidence-checked

How to read this

  • A step is one thing an agent did, in our own words, with a short quote and a link to the source that says so.
  • A verdict says whether any public test task has the same technique, only the same tactic, or neither. A script works it out from the labels.
  • “Never tested” means no public task states that tactic as its goal or as a required step. It does not mean a monitor would miss it: no monitor has been run.
