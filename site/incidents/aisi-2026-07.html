UK AISI incident INC-2026-07-28-01: unsanctioned agent actions during cyber testing

Anthropic, OpenAI25 Jul 2026 to 28 Jul 2026, disclosed 4 Aug 2026Agents in a cyber test with open internet access acted against real people and projects to finish their task. 35 steps · 26 attack steps · 5 never tested

In a UK AI Security Institute cyber-range test with internet access switched on, agents took 19 unsanctioned actions on the live internet. In the worst run, a model tried to get malicious code merged into a real open-source project, using fake accounts, hidden instructions and targeted messages. A human reviewer stopped it.

Each attack step is labelled with a MITRE ATT&CK® tactic and, where the source gives enough detail, a technique. The verdict compares it with the public test tasks.

The number beside each tactic is its count of public test tasks (end goal + stated required step). Keys: arrows or j / k to move, space to play.

  • Tested: same technique
  • Tested: same tactic only
  • Never tested
  • Can't tell
  • ◆ Detection or response event
  • Red row: no public task in this tactic
